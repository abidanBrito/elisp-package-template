* Installation

=elisp-package-template= targets GNU Emacs 27.1 and newer.

** From MELPA

With MELPA in your =package-archives=, install with =M-x= =package-install= =RET= =elisp-package-template= =RET=, or declaratively:

#+begin_src emacs-lisp
  (use-package elisp-package-template
    :ensure t
    :config
    (elisp-package-template-mode 1))
#+end_src

** From Git

Using =use-package='s built-in =:vc= keyword (Emacs 30.1+):

#+begin_src emacs-lisp
  (use-package elisp-package-template
    :vc (:url "https://github.com/abidanBrito/elisp-package-template"
         :branch "main")
    :config
    (elisp-package-template-mode 1))
#+end_src

#+begin_quote
On Emacs 29, fetch the same recipe with =M-x= =package-vc-install= =RET= https://github.com/abidanBrito/elisp-package-template =RET=.
#+end_quote

Or with [[https://github.com/radian-software/straight.el][straight.el]]:

#+begin_src emacs-lisp
  (use-package elisp-package-template
    :straight (elisp-package-template
               :type git
               :host github
               :repo "abidanBrito/elisp-package-template")
    :config
    (elisp-package-template-mode 1))
#+end_src

** From source

#+begin_src sh
  git clone https://github.com/abidanBrito/elisp-package-template.git ~/path/to/elisp-package-template
#+end_src

With =use-package=:

#+begin_src emacs-lisp
(use-package elisp-package-template
  :load-path "~/path/to/elisp-package-template"
  :config
  (elisp-package-template 1))
#+end_src

Or without it:

#+begin_src emacs-lisp
  (add-to-list 'load-path "~/path/to/elisp-package-template")

  (require 'elisp-package-template)
  (elisp-package-template-mode 1)
#+end_src
